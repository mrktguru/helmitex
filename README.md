# Helmitex Stickers

Проект интернет-магазина наклеек Helmitex.

## Разработка

Все изменения вносятся через git и пушатся на сервер.

### Ветки

- `main` — продакшн
- `claude/setup-project-server-git-cg86Z` — рабочая ветка разработки

### Workflow

```bash
# Внести изменения, затем:
git add .
git commit -m "описание изменений"
git push -u origin claude/setup-project-server-git-cg86Z
```
